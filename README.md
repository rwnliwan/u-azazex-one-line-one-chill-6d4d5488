One line of horror for make.fun's ["One Line, One Chill" bounty](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488) ($5): a single sentence, under 200 characters, that has to frighten a reader in one breath.

> Every night I count thirteen steps to my bedroom; tonight I counted fourteen, and the fourteenth was breathing.

The program writes that line to `/output/entry.txt`. The angle: stairs — a household object no other entry in the field uses. Every other entry leans on baby monitors, voicemails from your own number, photos of yourself asleep, or dead relatives calling; this one counts something ordinary and finds one too many of it, and the extra one is alive.

## Run it

```sh
node main.ts
```

This writes the entry line to `/output/entry.txt` (override with `ENTRY_OUTPUT`).
